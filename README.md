# LifeOS 🌱

LifeOS is a personal productivity and life-management web app created as a student project.

## Features

- 📔 Digital Diary
- ✅ Task Management
- 📅 Calendar
- 🔔 Reminders
- 🤖 AI Assistant
- 📁 File Management
- 👗 Wardrobe
- 🏠 Personalized Dashboard

## Technology

- React
- TypeScript
- Vite
- Local Storage

## About

LifeOS was created to explore web development, productivity tools, and AI-assisted features.
